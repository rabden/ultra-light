# Changelog

## 0.2.0

The Linux build, rebuilt on mygo: Google results in the panel, a tray
icon, the first-run welcome, Codegraff sync with the key in the desktop's
keyring, Raycast extensions and script commands, and updates that install
themselves. The shortcut is Super Space, set as a GNOME custom shortcut on
GNOME, and a key the desktop holds can be taken over (and given back).
Ask Grok and Search X are gone: the rows end with Google.
